thingd
Object-first data engine

A fast object-first data engine for modern applications and AI agents. Persistent storage, durable queues, event streams, full-text search, and MCP-native access.

Get started → GitHub Docker
// Install
$ npm install thingd

// Store, search, and process
import { ThingD } from "thingd";
const db = await ThingD.open(":memory:");

// Store an object
await db.put("notes", { id: "hello", text: "Hello world" });

// Append an event
await db.events.append("notes", { type: "created" });

// Push a job
await db.queue("embed").push({ object: "notes/hello" });

// Search
const hits = await db.search("hello");
console.log(hits.length); // 1

Everything in one engine

No more stitching together databases, queues, search engines, and agent tooling.

🗄️

Object store

Versioned JSON records in named collections. No schema required. Put, get, delete, list.

📋

Durable queues

At-least-once delivery with leases, retries, delays, idempotency keys, and dead-letter queues.

📡

Event streams

Append-only timelines with auto-incrementing sequences. Built for audit trails and replication.

🔍

Full-text search

SQLite FTS5 with Porter stemming, metadata filters, and recency-weighted ranking.

🤖

MCP-native

12 built-in MCP tools. AI agents can read, write, search, and process jobs out of the box.

⚡

Multi-mode

Embedded, sidecar, or cluster. In-memory or persistent. Same API everywhere.

Built-in MCP tools for AI agents

thing_search · search objects and events
thing_get · get an object by ID
thing_put · create or update an object
thing_delete · delete an object
thing_events_append · append to a stream
thing_events_list · list stream events
thing_queue_push · enqueue a job
thing_queue_claim · claim a job
thing_queue_ack · acknowledge success
thing_queue_nack · retry or fail a job
thing_queue_list · list queue jobs
thing_queue_dead · list dead-letter jobs

EOF
