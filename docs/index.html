thingd

A fast object-first data engine for applications and AI agents.

// Install & use thingd
npm install thingd

import { ThingD } from "thingd";
const db = await ThingD.open(":memory:");

await db.put("notes", { id: "hello", text: "Hello world" });
const result = await db.get("notes", "hello");
console.log(result.text); // "Hello world"

Object store

Store versioned JSON records in collections. No schema required.

Durable queues

At-least-once queues with leases, retries, delays, and dead-letter.

Event streams

Append-only timelines with auto-incrementing sequences.

Full-text search

SQLite FTS5 with stemming, metadata filters, and recency scoring.

MCP-native

12 built-in MCP tools for AI agents. No custom integrations needed.

Multi-mode

Run embedded, sidecar, or cluster — same API across all modes.

Get started

npm Docker
# Install the SDK
npm install thingd
