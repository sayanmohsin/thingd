Everything in one engine

No more stitching together databases, queues, search engines, and agent tooling.

🗄️

Object store

Versioned JSON records in named collections. No schema. Put, get, delete, list. Auto-versioning.

📋

Durable queues

At-least-once with leases, retries, delays, idempotency keys, and dead-letter queue.

📡

Event streams

Append-only timelines with auto-incrementing sequences. Built for audit and replication.

🔍

Full-text search

SQLite FTS5 with Porter stemming, metadata filters, and recency-weighted BM25 ranking.

🤖

MCP-native

12 built-in MCP tools. AI agents read, write, search, and process jobs without custom code.

⚡

Multi-mode

Embedded, sidecar, or cluster. In-memory or persistent SQLite. Same API everywhere.

Built-in MCP tools

AI agents interact with thingd through 12 standardized tools — no custom integrations needed.

thing_search · search objects and events
thing_get · get object by ID
thing_put · create or update
thing_delete · delete object
thing_events_append · append to stream
thing_events_list · list stream events
thing_queue_push · enqueue job
thing_queue_claim · claim job
thing_queue_ack · acknowledge success
thing_queue_nack · retry / fail
thing_queue_list · list queue jobs
thing_queue_dead · list dead-letter jobs

Get started

Choose your path — SDK, Docker sidecar, or CLI.

$ npm install thingd

// app.mjs
import { ThingD } from "thingd";
const db = await ThingD.open(":memory:");
await db.put("notes", { id: "1", text: "hello" });
const obj = await db.get("notes", "1");
console.log(obj.text); // "hello"
$ docker pull sayanmohsin/thingd
$ docker run -p 8757:8757 sayanmohsin/thingd

// → HTTP MCP server at http://localhost:8757/mcp

// With persistence:
$ docker run -p 8757:8757 -v ./data:/data sayanmohsin/thingd

// With auth:
$ docker run -p 8757:8757 -e THINGD_AUTH_TOKEN=secret sayanmohsin/thingd
$ npm install -g thingd-cli

$ thingd
// → Interactive TUI Dashboard

$ thingd mcp --driver native
// → MCP stdio server for Claude / Cursor

$ thingd search "hello world" --limit 5
// → JSON output for scripting

Embedded

Sidecar

Cluster

Leader/follower with write forwarding and read replicas. K8s ready.
